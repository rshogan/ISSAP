# Usage
"User accepts all risk" - tongue in cheek joke but not really.  If you can't check the code and assess the risk of running a small python web server locally, you probably shouldn't be preppping for the ISSAP.  

Download the project.  
Put it in a folder and run "run.bat" (Windows) or "./run.sh" (macOS / Linux)  
The app should open in your default web browser.  Tested in Google Chrome only.  
Both scripts just start a local Python 3 web server. Nothing is installed.  
I haven't tested on mac/linux - and probably won't - but you should be able to get the python server to run even if run.sh is faulty.

## Desktop app (optional)
There is also an Electron wrapper, so it can run in its own window instead of a browser tab.  

To build a Windows installer, Node.js is required:  
(can't upload an .exe installer to github, it exceeds a single file size limit)
1. `winget install OpenJS.NodeJS.LTS`  
2. run "build-installer.bat" - it npm installs and writes `dist\ISSAP-Cyber-Redemption-Setup-<version>.exe`  

The installer is per-user, so it does not need admin rights.  It is unsigned, so SmartScreen will warn on first run.  

## Saved Games
On Windows, Your saved games are stored in your  %LocalAppData%  folder - for Chrome it is:  
%LocalAppData%\Google\Chrome\User Data\Default\Local Storage\leveldb%  

On Linux, I assume they would be somewhere in usr land.  Not sure!
